# 기능확장 6건 — 최종 배포 결재 요청 (2026-08-20)

대표가 오늘 요청한 6건을 코드에 반영했고, PRD 확정→부서 설계→구현→QA/보안 풀검수(+재작업)→법률 스크리닝까지 전 게이트를 통과했습니다. 남은 것은 **운영 서버(sumeungil.co.kr) 배포 승인**뿐입니다.

## 무엇이 바뀌나

1. **마이페이지 허브** — 로그인하면 마이페이지로 이동, "여행 준비" 섹션에서 취향분석·AI코스짜기 시작
2. **AI 문답(컨시어지) 삭제** — `/ask` 채팅형 인터페이스 제거, 대신 AI 코스짜기 화면에 짧은 의견 입력(1~2줄)을 통합. 신규 API 0개(기존 온보딩 API 재사용), LLM 호출도 오히려 요청당 2회→1회로 줄어듦
3. **혼잡 지도 삭제** — `/congestion`의 지도 컴포넌트만 제거, 혼잡도 현황판·배지·API는 그대로
4. **공유 코스 좋아요 + 정렬** — 하트로 좋아요, "최신순/좋아요순" 정렬
5. **여행 팁 AI 개인화** — 로그인+취향프로필 있으면 맞춤 팁, 실패 시 항상 기존 정적 5건으로 폴백(화면이 비지 않음)
6. **AI 현황 조사** — 요청대로 변경 없이 현황 문서만 작성(`02-ai-strategy-현황.md`)

## 지켜진 것 (조사로 확정한 안전장치)
- 2026-08-18 보안감사로 막 고친 "공유 코스 위조 방지" 로직은 **코드 한 글자도 안 건드림**(diff 0으로 검증)
- 로그인 게이트(하트·코스담기 도중 로그인)는 리다이렉트 대상에서 제외 — 하던 행동을 잃지 않음
- 여행 팁은 사용자 자유텍스트·스팟명을 프롬프트에 넣지 않고, LLM이 실패해도 항상 기본 팁이 뜸

`verify_likes.py` 50/50, `verify_tips.py` 52/52, `verify_course_payload.py` 전건 통과, 프론트 `tsc` 0에러, `import app.main` 정상(23 라우트).

## 대표가 결정할 것

**배포 여부와 시점.** 6건을 묶어서 한 번에 배포하는 것으로 설계했습니다(부분 배포 시 "마이페이지는 허브인데 의견입력은 없는" 중간 상태가 생기고, DB 스키마 변경(좋아요 테이블 신설)도 있어 롤백 단위를 하나로 묶는 게 안전합니다).

- 배포하면: 컨시어지(`/ask`) 라우터가 사라지므로 프론트·백엔드가 **반드시 같은 배포**로 함께 올라가야 합니다(이미 그렇게 준비됨).
- 배포 전 참고: 이 저장소에서 **다른 세션이 Prometheus/Grafana 관측 연동 작업을 동시에 진행 중**이라 워킹트리에 미완료 변경이 남아있습니다. 이번 배포는 그와 무관하게(이 6건만) 진행 가능합니다.

승인해주시면 바로 배포 진행하겠습니다.
