# 약관·개인정보처리방침 대조 검토 (2026-09-20)

## 범위와 결론

v0.6.6 (`origin/main` 341354e), `origin/develop` 3f11588의 코드와 공개 법령을 대조했다.
이번 수정은 확인된 불일치를 보완하는 것이며, 서비스의 법률 적합성을 인증하거나 위치정보사업 신고를 완료하는 작업이 아니다.
운영 서버의 환경변수·DB·로그·계약에는 접근하지 않았다. 운영 배포는 별도이며 이 변경으로 스탬프 기능을 재개하지 않는다.

## 사용자에게 확인한 사실

- 공모전 출품작이며 운영 주체는 숨은 팀.
- 서버 소재지는 대한민국.
- Gemini는 현재 무료 API. 향후 수익·이용자 증가 시 유료 전환을 검토 중이며, 아직 유료로 안내하지 않는다.
- 담당자·호스팅 업체·로그 및 백업 보존기간은 미확정. 기존 문의 이메일은 유지했다.

## 아직 확정해야 하는 사항

1. 개인정보보호책임자 성명 또는 담당부서와 연락처. 현재의 팀명·문의 이메일을 정식 책임자 지정 완료로 보지 않는다.
2. 실제 호스팅 수탁업체와 위탁 업무, 재위탁·백업 저장소/국가. 국내 서버라는 사실만으로 모든 처리가 국내에서 끝난다고 보지 않는다.
3. 접속·오류 로그 및 백업 보존기간, 자동 삭제 운영 증거, 복구 시 삭제 정보 재노출 방지 절차. backup.sh의 기본 14일은 운영값이 아니며 외부 저장소 수명주기를 입증하지 않는다.
   - **2026-09-20 조치**: 대표 결정으로 로그 90일·백업 14일(서버 로컬, 외부 저장소 없음)을 처방 1·4·6·7항에 명시. 로그는 `deploy/logs/retention.sh`(log-retention 서비스)가 90일 뒤 삭제, 백업은 backup.sh 기본 14일. 복구 시 삭제 재반영 절차는 `deploy/DEPLOY.md`. 서버 적용 후 `ls deploy/logs/nginx`·`ls deploy/backups` 로 운영 증거 확인 필요.
4. 개인정보 항목별 처리 근거와 별도 동의 필요 여부. 처리방침 확인 체크박스는 별도 수집·이용 동의의 대체물이 아니다.
5. Gemini 무료 API에 개인정보를 보내지 않아야 한다. 패턴 가림은 완전한 익명화가 아니며, 자유 서술에 개인정보가 남을 수 있다. 적용 약관·계정 조건에 따른 수령자/국가/이전시기·방법/보유기간·근거/거부 영향과 보호조치를 확정해야 한다. 유료 전환만으로 국외이전 문제가 자동 해결되지 않는다.
6. 위치 인증을 재개하려면 사업자 지위·신고/특례, 약관·사전 동의, 이용사실 확인자료, 보관/파기 및 권리 행사 절차를 먼저 확정한다. 기존 스탬프를 이미 처리한 사실은 기능 중단으로 사라지지 않는다. 유지 목적·기간 및 삭제 방침도 결정해야 한다.
7. 새 동의 버전 배포 전에 개정 공지와 적용 시점을 확인한다. API의 일반 로그인 검사 자체가 약관 동의를 강제하는 것은 아니다. 이번 수정은 기존 /me → ConsentModal 재동의 경로를 사용하며, 모든 API의 권한 체계를 변경하지 않았다.

미확정 정보를 공개 문구에 가상의 업체·기간·신고번호로 채우지 않았다. 따라서 위 항목이 남은 상태에서 '약관 검증 완료 = 법적 요건 모두 충족'으로 안내하면 안 된다.

## 검증

- 프론트 lint 및 프로덕션 빌드 실행.
- 동의 버전 변경에 맞춰 기존 인증 회귀 테스트의 현재 버전을 상수로 참조하도록 변경.
