서울 실경계 + 실좌표 코스선

서울시 실제 행정경계(2018 통계청 경계, southkorea-maps 공개 데이터)를 단순화해 윤곽만 그렸고, 난지한강공원 → 경복궁 → 남산 팔각정 → 서울숲 4곳은 저희 스팟 데이터의 실제 위경도를 그대로 투영한 좌표입니다. 좌표·경계 둘 다 지어낸 값이 아닙니다 — 순서는 임의 예시입니다.

서울특별시 · 행정경계 단순화본

이 스케치는 화면에 바로 쓰는 최종본이 아니라 "실경계 + 실좌표로 이렇게 보일 수 있다"를 보여주는 확인용입니다. 좋으면 이 방식(시/도 경계 데이터 수집 → 단순화 → 코스 좌표 투영)을 17개 지역 전체로 자동화하는 작업을 이어서 진행하겠습니다.
