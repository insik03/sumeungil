과제 2번(우리가 선택): **"유명 관광지 중심의 관광객 쏠림 현상으로 인한 특정 명소의 오버투어리즘(과밀화) 문제"**

붙임 자료의 "(예시) 서비스"·해시태그는 **참고용일 뿐 개발 의무가 없다**(12페이지 명시: "본 자료는 지정과제 이해도 제고를 위한 참고용 예시이며, 해당 내용으로의 개발 의무나 개발에 따른 별도 이익/불이익은 없습니다").

1차 심사자료 제출 시 요구되는 건 "해시태그(예시 참고 **또는 자체 도출**)와 연관된 기능 구현 내용에 대한 기능설명서" — 즉 **우리가 자체적으로 해시태그를 정의**해도 된다.
