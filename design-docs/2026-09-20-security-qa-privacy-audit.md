# 숨은길 보안·QA·개인정보 점검

기준: develop `ebff3f6`와 기존 로컬 변경. 이번 작업은 코드·문서 수정과 읽기 전용 운영 확인이다. 이슈 생성, 커밋, 푸시, 릴리스, 배포는 하지 않았다.

## 판단

기능 확장에 비해 계정 경계, 저장 데이터 동기화, 개인정보 고지가 뒤처진 부분이 있었다. 재현 가능한 문제를 로컬에서 수정했다. 아래 미확인 항목 때문에 서비스 전체의 보안·법률 적합성이나 배포 준비가 완료됐다고 판정하지 않는다. 실사용자 OAuth, 모바일 화면, 전체 API 침투 테스트를 완료한 검수도 아니다.

## 수정한 부분

| 분야 | 발견한 문제 | 보완 |
|---|---|---|
| 인증 | 선택적 인증이 로그아웃으로 폐기된 session_epoch를 검사하지 않음 | 현재 DB epoch와 비교, 폐기된 세션은 비로그인 처리 |
| 계정 연결 | OAuth 연결 완료 시 서명만 검증, DB 세션 폐기 확인 누락 | 공통 require_login으로 검사; DB 장애도 팝업 오류로 종료 |
| Google 인증 | email_verified 누락을 검증 완료로 간주 | 명시적인 boolean true만 허용 |
| 계정 통합 | 원본 계정을 지우면서 다른 연결된 로그인 수단도 유실 | 충돌하지 않는 로그인 수단을 함께 보존; 충돌 시 병합 거부 |
| 탈퇴 | 서버 삭제 실패를 삼키고 화면에서는 완료 처리 | 성공 응답 뒤 로컬 정리; 오류 표시; 저장소 예외가 서버 성공을 뒤집지 않게 분리 |
| 로그아웃 | 서버 종료 실패를 숨김 | HTTP 오류·네트워크 실패 안내 추가 |
| 저장 목록 | 로컬 캐시를 매번 업로드하여 다른 기기에서 지운 항목이 부활 | 서버 목록을 정본으로 사용; 계정 캐시는 메모리로 격리 |
| 저장 목록 | 이전 계정의 늦은 응답·연속 저장 요청이 현재 표시와 충돌 | 인증 세대·조회 revision 확인, 쓰기 직렬화, 스팟별 실패 복구 |
| 저장 표시 | 비동기 동기화 후 상세 하트·마이페이지 개수 미갱신 | 공통 변경 이벤트를 목록·버튼·상세·마이페이지에서 구독 |
| 이전 기기 저장 | 게스트 목록을 계정으로 자동 이전하거나 로그아웃 시 제거 | 자동 업로드 중단, 기존 기기 목록 보존 |
| 저장 상한 | 개수 검사와 INSERT가 별도 트랜잭션; 상한에서 기존 항목 갱신도 거부 | 사용자 행 잠금 안에서 개수 검사, 기존 항목은 갱신 허용 |
| CSP 보고 | 잘못된 JSON 내부 타입·공백 지시어로 500, 전체 본문을 읽은 뒤 크기 검사 | 타입·공백 검사, 스트림 누적 8KB 초과 시 중단 |
| 접근 로그 | 쿼리를 제외해도 Referer에 외부 URL의 민감한 쿼리가 남을 수 있음 | Referer와 불필요한 User-Agent 필드 제거; 원본 IP 로그는 별도 고지 |
| 처리방침 | 네이버, 계정 저장·통합, 위치 권한, 백업 고지가 실제 기능과 불일치 | 관련 항목과 개정일 보완, 탈퇴 삭제 범위를 운영 DB 기준으로 명시 |

## 검증 결과와 한계

- 프론트 TypeScript 검사 및 ESLint 통과.
- `frontend/scripts/verify_saved_spots.cjs`: 서버 정본, 삭제 항목 재업로드 방지, 이전 계정 응답 폐기, 쓰기 순서, 저장 실패 복구, 서로 다른 스팟 중 일부만 실패, 게스트 목록 보존, 탈퇴 실패·스토리지 오류 동작 통과. CI에도 추가.
- `backend/scripts/verify_security_boundaries.py`: 폐기/현재 세션, 잘못된 CSP 입력, 공백, 호스트만 집계, 초과 스트림 조기 중단 통과. 기존 CI의 verify 스크립트 순회에 포함.
- Python app 및 verify 스크립트 171개 구문 검사 통과. `git diff --check` 통과.
- 기존 `verify_auth.py`에 제3 로그인 수단 보존 검증, `verify_saved_spots.py`에 상한에서 갱신/신규 저장 구분 검증 추가.
- **PostgreSQL 통합 테스트 미실행**: 로컬 PostgreSQL 실행 파일이 없고 Docker 엔진이 응답하지 않음. 설치된 Docker Desktop 시작도 시도했으나 CLI가 응답하지 않아 중단. 운영 DB는 사용하지 않았다. CI 또는 격리 PostgreSQL에서 인증·통합·저장·동시성 검증 필요.
- **nginx 설정 변경은 nginx -t 미실행**. 배포 환경에서 문법 확인 후 재시작 필요.
- **npm 의존성 취약점 조회 미완료**: 보안 권고 서버가 503 점검 응답. 취약점 없음으로 간주하지 않음.
- 실 OAuth 제공자 로그인, 계정 통합 후 세 제공자로 재로그인, 실 브라우저 다기기 동기화와 전체 모바일 QA는 배포 전 별도 검증 필요.
- 독립 qa-reviewer와 code-quality-reviewer(gpt-5.6-sol/high)를 실행했다. 지적한 상태 표시·게스트 보존·DB 장애·부분 저장 실패·탈퇴 후 저장소 오류는 후속 수정과 해당 로컬 테스트로 확인했다. 변경 후 별도의 전체 독립 재승인 판정은 받지 않았다.

## 운영에서 확인한 사실

2026-09-20 02:29 KST 공개 API·헤더 읽기 기준:

- health HTTP 200.
- `/api/v1/health/llm`: provider=gemini, 최근 1시간/24시간 429 각 6건, fallback_suspected=true. 로컬 기본값 Ollama와 다르다. 로컬 LLM 전환 완료로 안내하면 안 된다.
- HSTS max-age=86400, X-Content-Type-Options=nosniff.
- 강제 CSP는 frame-ancestors 'self'; 나머지는 Report-Only. 보고 모드만으로 스크립트 주입을 차단한다고 설명하면 안 된다.
- 기존 `frontend/next.config.js` 로컬 프록시는 운영 API를 가리킨다. 사용자 기존 작업이어서 변경하지 않았으며, 이 프록시로 계정 생성·삭제·저장 E2E 테스트를 하지 않았다. 향후 QA는 별도 백엔드로 분리해야 한다.

## 공개·배포 전에 남은 사항

1. **개인정보 문구 확정**: 개인정보 담당자의 이름/담당부서 및 실제 연락처, 호스팅 위탁 업체·업무, 서버 접속/오류 로그의 보존기간·접근 권한을 확인해야 한다. 현 방침의 일반적인 운영자·호스팅 표현만으로 충분하다고 보지 않는다.
2. **백업과 삭제**: backup.sh 기본 보존 설정은 14일이지만 운영 적용 여부와 파일 삭제 주기는 미확인. 백업 삭제 상한, 복구 시 탈퇴 데이터가 되살아나지 않는 절차를 확정해야 한다. 백업에 남겨도 무조건 적법하다는 판단은 하지 않는다.
3. **AI 처리**: 운영은 아직 Gemini이다. 무료 API의 개인정보 입력 제한과 국외이전 근거·항목·국가·시기/방법·수령자·보유기간·거부 방법을 실제 계약에 맞게 확인한다. 문자열 마스킹이 완전한 익명화를 보장하지 않는다. Ollama 전환 시 국내/외 실제 호스팅 위치와 외부 fallback을 확인하고 방침을 다시 맞춘다.
4. **약관 동의**: 개인정보처리방침 고지와 개인정보 수집·이용/국외이전 동의가 필요한 경우의 법적 근거를 구분해 검토한다. 이번 문구 보완의 공지·재동의 필요 여부와 TERMS_VERSION은 최종 공개 내용 확정 후 함께 결정한다. 현재 버전을 임의로 올려 전체 이용자 재동의를 강제하지 않았다.
5. **CSP/운영**: 실제 보고를 검토하고 네이버 OAuth·지도·폰트 등을 검증한 뒤 강제 정책으로 전환한다. HSTS 기간 확대는 인증서 자동갱신 점검 후 진행한다.
6. **DB와 추천 품질**: 계정 병합 동시 요청, 좋아요 중복 제거 후 집계, 병합 결과가 저장 상한을 넘는 경우를 추가 검증한다. 추천의 혼잡도는 원천 갱신 시각·추정/실측·폴백 여부를 실제 화면에서 다시 확인해야 한다. 현재 작업만으로 추천 정확도를 인증하지 않는다.
7. **저작권·외부 데이터**: TourAPI 사진별 이용조건/출처 및 지도 제공자 표시, 로고·폰트 라이선스 증빙을 출시 체크리스트에서 확인한다. 전체 자산 권리 검증은 이번에 완료하지 않았다.

## 법률 검토 근거

법률 1차 스크리닝이며, 계약 및 실제 운영 자료까지 확인한 법률 자문은 아니다.

- 개인정보처리방침에는 보유기간·파기·해당 시 위탁·권리 행사·담당 연락처 등 실제 처리 내용이 포함되어야 한다: [개인정보 보호법 제30조, 2026-09-11 시행](https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1033214957).
- 국외이전은 적용 가능한 근거와 고지/동의 요건을 별도로 확인해야 한다: [개인정보 보호법 국외이전 조항](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1020398611).
- 무료 Gemini에 개인정보·민감정보를 제출하지 말라는 제한과 데이터 사용 조건 확인: [Google Gemini API 추가 약관](https://ai.google.dev/gemini-api/terms).
